GESTOR DE FACTURACION - FRUTAS EL HORTAL - VERSION 2

IMPORTANTE
1. Extrae/descomprime el ZIP completo.
2. No abras index.html desde dentro del ZIP.
3. Abre ABRIR_APLICACION.bat en Windows o index.html después de extraerlo.

NOVEDADES
- Cada factura admite uno o varios productos.
- "Añadir producto de la tabla" agrega tantas filas como necesites.
- "Crear producto nuevo" permite darlo de alta sin salir de la factura y lo añade a la fila.
- Cada producto puede tener Precio/kg, Precio/unidad o ambos.
- En cada línea eliges kg o unidad. Solo se habilita la cantidad correspondiente.
- CSV de productos y detalle de facturas actualizados.

DATOS Y COPIAS
Los datos se guardan localmente en el navegador. Usa "Copia JSON" periódicamente.
Los botones CSV exportan tablas compatibles con Excel.
Para crear PDF usa "Guardar PDF / Imprimir" y selecciona "Guardar como PDF".
